New curriculum and numbering. This v2 list replaces the previous 286-card list. Record all items from scratch using the IDs below. The game and this list use exactly the same order.

744 cards across 49 groups: 391 word and number cards first, then 171 short, 150 medium, and 32 longer sentences. Every vocabulary card is revisited in sentence practice.

  1. Use Voice Memos in a quiet room. Record one suggested batch at a time.
  2. Say the item's number in English, pause for about one second, then say the complete Hebrew word or sentence naturally. Leave about two seconds before the next item.
  3. Name each file with its edition and range, such as Hebrew v2 001–008. You only need to speak the number, not “v2”.
  4. If you make a mistake, say “again”, repeat the number, and read the item again. Send the audio files in chat for splitting and matching.

For sentences: record the full sentence as one natural utterance. Do not pause between every word. English is a meaning cue; record only the Hebrew. Gender labels describe the intended form, and sentence practice also shows inflected forms. Standalone numbers use feminine counting forms; counted nouns may require masculine forms.

This is a practical learning curriculum, not a developmental assessment. Existing first-eight test clips remain available until replaced. Recordings added to the public website can be heard by anyone who visits it.
